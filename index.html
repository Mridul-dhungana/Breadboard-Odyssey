Build

Supports R, C, DC voltage sources and one named NE555 terminal profile (TIMER_DEMO — interface only).

Checklist

    Investigate

    Yellow holes are the requested probe points. Capture reads from Arduino when connected, otherwise mock ADC (or enter volts).

    Repair

      Mock fault applies only when Arduino is offline. With a live board, fix the real wiring then Verify with Capture reading.

      Verify

      Re-measure highlighted nets from Arduino (or mock). Healthy rails should sit near expected voltages.

      Parts tray

      Breadboard

      Drag a part onto a hole, or select it and click a hole. Hover a part to inspect its pins. Hold or drag it to reveal valid anchors. During Investigate/Verify, yellow holes request a probe.

      Terminal → pin → hole

      Suggested jumpers

      Select a route to highlight its endpoints. Add wire draws it on the board. The first positive DC supply uses the top rails.
